Getting the data ready
0

Setup

What it does
  • Loads the tools (TensorFlow, scikit-learn, pandas).
  • Fixes the random seed (42) so every run gives the same numbers.
Output
  • TensorFlow 2.15.0 confirmed.
1.1–1.2

Find the data and count the dummy sweeps

What it does
  • Finds the three datasets on the laptop.
  • Loads 90 dummy-belly sweeps and counts how many pictures show each view.
Output
19,405pictures
90sweeps
98.2%show no key view
  • Key views: only 42 (head) to 134 (spine) pictures each.
  • 36 sweeps hold no key view at all.

Why it matters: guessing "nothing" every time scores 98%, so plain accuracy is useless here.

1.3

Prepare every picture

What it does
  • Finds the scan area once, from 300 pictures.
  • Crops, brightens, squares and resizes each picture to 224 × 224.
  • Saves the result so later runs skip this step.
Output
  • Crop box (50, 28, 657, 467), shared by all pictures.
  • One saved file of prepared pictures.

Why it matters: one probe and one depth means one crop fits every picture.

1.4

Clean the labels

What it does
  • Removes duplicate pictures that carry conflicting labels.
  • Sets aside "no view" pictures within 3 frames of a key view: they look almost the same.
Output
2conflicts removed
1,422look-alikes set aside
345key-view pictures
  • Look-alikes are never used for learning, but are still tested on.
1.5

Match the real datasets to our views

What it does
  • Maps Spanish and African labels onto our five views.
  • Takes 400 Spanish pictures per view, to keep views balanced.
  • Keeps all 450 African scans for testing only.
Output
2,000Spanish pictures used
450African test scans
  • Spine has no match in the real data.
  • Ghana and Uganda have no heart pictures.
  • A picture grid confirms each column is one view.
Building and testing the model
2

Turn pictures into numbers

What it does
  • Two ready-made image models (EfficientNet-B0, MobileNetV2) describe each picture.
  • Done once and saved.
Output
2,560numbers per picture
  • Shapes: dummy (19,405), Spain (2,000), Africa (450).

Why it matters: reusing models trained on millions of everyday images means we don't need millions of scans.

3

Train the model and test it fairly

What it does
  • A simple classifier learns the 5 views plus "nothing".
  • Extra practice on the most look-alike "nothing" pictures.
  • 5-fold test split by sweep; settings tuned only on training sweeps.
Output
  • Cross-validation finished in 154 seconds.
  • Every sweep is scored by a model that never saw it.

Results on the dummy sweeps

What it does
  • 4.1 scores pictures and whole sweeps.
  • 4.2 scores each view and shows where it gets confused.
  • 4.3 compares sweep directions.
Output

  • Best views: head 0.59, heart 0.58. Worst: thigh bone 0.04.
  • Vertical sweeps work best: 72% of views found, 95% of good sweeps passed.
5

The real test: African scans

What it does
  • Tests on 450 real African scans the model never learned from.
  • Compares a model trained on the dummy only with one that also saw Spanish pictures.
Output
21%right view, dummy only
80%right view, + Spain
  • By country: 72% (Algeria) to 92% (Uganda).

Why it matters: our clearest result. Real pictures turned a guessing model into a useful one.

Extra checks and the midwife visit
7

Breech flag: head-down or bottom-first?

What it does
  • Uses the whole sweep to guess the baby's position.
  • 7.1 checks it isn't just using "no head seen".
Output
82%correct (guessing 54%)
31 / 41breech sweeps caught
  • 43 of 49 head-down sweeps right; AUC 0.86.
  • "No head seen" rules score only 0.38–0.45.

Why it matters: one dummy in four positions, so this shows it can be done, not clinical accuracy.

Brain check (experimental)

What it does
  • Learns 15 brain conditions from a public image set.
  • 8.1 turns scores into safe messages: refer, consult, or not assessed.
  • 8.2 tests normal heads from our other datasets.
  • 8.2a saves the check for the app.
Output
90%condition named right
1.00normal vs abnormal AUC
25%false alarms, African heads
  • Spain: 3% false alarms. Dummy: all refused as unfamiliar.

Why it matters: perfect on its own data, wrong elsewhere. It learned the dataset's look, so it stays experimental.

11

Conclusions

  • Real pictures matter most: 21% → 80% on African scans.
  • The tool works best as a picture-quality helper, not a diagnosis tool.
  • A single vertical sweep pattern would help directly.
  • Next: Kenyan data labelled by specialists, a phone test, and a clinic pilot.
